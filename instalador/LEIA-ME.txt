MakerWorld to Any (makerworld-to-any) - Claude Code skill
Made by Megatic - https://megatic.pt
https://github.com/GodFaizT/makerworld-to-any

Adapts Bambu Studio / MakerWorld 3MF projects for Anycubic printers
(Kobra X, Kobra 4, Kobra S1, S1 Max, Kobra 3, 3 Max, Kobra 2, Kobra 1) in Anycubic Slicer Next,
with each printer's profiles, and slices them to give the time and grams.

Install
-------
1. Unzip this zip.
2. Double-click instalar.bat (copies the folders to %USERPROFILE%\.claude\skills\).
3. Open a new Claude Code session.

Commands
--------
  /kobrax "C:\...\model.3mf"                   adapt for the Kobra X
  /kobra4, /kobras1, /kobras1max, /kobra3, /kobra3max
  /anycubic Kobra 2 Neo "C:\...\model.3mf"     any other Anycubic
      after the file you can add requests: "10 cm tall", "0.6 nozzle", "in PETG", "gold",
      "with my profiles", "save the g-code"

  /any-plates "C:\...\adapted.3mf"             move objects between plates, one per plate, move parts apart
  /any-colors "C:\...\adapted.3mf"             per-part colors, add a color, change the material
  /any-undo                                    restore the previous version of a file
  /any-settings                                your profiles, printer, folders and prices
  /any-doctor test                             check that everything works
  /any-update                                  update to the latest version

Or just ask: "adapt this file for the kobra x: ..."

Needs Anycubic Slicer Next (C:\Program Files\AnycubicSlicerNext) and Python 3.
numpy is optional (pip install numpy): it measures the real gap between parts and lets the skill move them apart.

instalar.bat installs it for Claude Code. For Codex (ChatGPT) or Antigravity (Gemini), see
"Install" on https://github.com/GodFaizT/makerworld-to-any (npx skills add ... -a codex,
or agy plugin install https://github.com/GodFaizT/makerworld-to-any).
